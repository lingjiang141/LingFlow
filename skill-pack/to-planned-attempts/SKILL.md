# 本轮跨票协调

- 只记录主控需要决定的跨票顺序、共享边界和停手条件，引用相关票号。涉及旧票时写明本轮需要调整的事项。
- 将实际技术前置、关键读写和共享资源写到相应票的派发字段。LingFlow 运行时判定冲突、等待前置并放行。没有额外协调时写一行「本轮无额外跨票协调。」。
- 保存为项目内的 `planned-attempts.md`，供 `dispatchPlan` 引用并冻结。票内复用点、实现步骤和测试细节由责任开发接票后决定。
