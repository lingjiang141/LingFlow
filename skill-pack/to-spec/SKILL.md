# 整理规格

- 无有效基线时写完整规格，包括目标、适用对象、业务边界、可观察验收、直接回归与未决项。按已有项目约定保存。
- 有基线且目标变化时只写本轮差异，引用有效基线和批准变化，区分新增、移除、保留条件。
- 恢复既有行为时用修复记录，包含原验收条款、预期与实际、最小复现、影响及验证边界。
- 记录真实授权来源，未决取舍明确为草案。需求明确并已授权执行时由主控用 `approve` 登记或沿用已有记录。精确路径、命令与成员在 [拆票与派单](../to-tickets/SKILL.md) 时核实。

需要详细结构时读取 [完整规格模板](references/full-spec.md) 或 [差异规格模板](references/diff-spec.md)，沿用已有有效规格及批准差异。
