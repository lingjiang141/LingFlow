# LingFlow 桌宠进度概览

点击主窗口的“桌宠模式”，或关闭主窗口，即可保留桌面的透明动画桌宠和后台服务。拖动桌宠可移动位置；单击查看当前项目与 Spec 的进度，再次单击、点击关闭按钮或按 Esc 收起。切换到别的应用不会收起概览。

票卡按“已收口 → 开发中 → 等待准入”顺时针排列，每类独立滚动，点击票卡可展开概述与等待原因。桌宠跟随主窗口所选项目和 Spec，也可在概览上方切换；默认显示最近登记的规格周期的“本轮全部票（含追加）”。同一项目下同一 Spec 文件的各次冻结版本共同组成一个周期，原有 5 票再追加 2 票、1 票时会合并显示 8 票，并按 8 票计算进度。不同 Spec 路径的历史周期保持分开；需要核对某次冻结范围时仍可选择“单个版本”。也可显式选择全部项目任务。以上仅合并展示，不改动原票的冻结契约或证据。技术收口比例统计 ready/trial/accepted，已验收数量单列；已被替代或已释放范围的票保留历史展示，不计入进度分母。

右键桌宠切换 DSH、Claude、GPT、Gemini、Grok。待机动作完整播放两遍后随机切换，始终排除该形象的“写代码”；概览保持打开时连续播放“写代码”，收起后恢复随机。动作按素材元数据的帧率和帧数播放，通常一遍约 10 秒。无音效、自动走动或额外养成功能。

动画来源固定为 hunmer/aboutme-pets 的 `ee29ca4abb489e9257f41ab889a1db115323a267`，共收录五种形象的 565 条动作。每种形象的待机、“写代码”和部分随机动作随应用提供，其他动作第一次播放时从固定上游版本下载、校验并缓存；断网时使用内置动作。缓存上限约 256 MiB，渲染只保留当前和下一条动画。位置与形象选择保存在桌面用户数据目录的 `pet.json`。

保持透明窗口外围的鼠标穿透；多屏拖动与展开时限制在屏幕工作区内。后台断线时显示“连接中断”，不会把上次进度伪装为实时结果。恢复主窗口可用托盘或右键菜单；退出应用请使用托盘的“退出 LingFlow”。

素材使用限制与署名见 [动画来源说明](../desktop/pet-assets/ATTRIBUTION.md)：DSH 素材禁止商用，其余四种形象遵循上游 CC BY-NC-SA 4.0 声明。

验证：`node --test tests/pet.test.mjs` 检查分组、进度、两遍循环规则、边缘定位与资源校验；`node scripts/pet-smoke.mjs` 使用隔离的 Electron 窗口验证实际绘制、约 20 秒切换、拖动、持续查看、全部形象切换和长列表，并在 `.validation/pet-smoke-*` 保存截图。`npm run test:desktop` 验证主窗口关闭后服务和托盘生命周期。
