# 规格实施

读取原规格和已批准差异，将验收条款映射到原票。缺票时使用 [拆票](../lingflow-to-tickets/SKILL.md)。确认当前 Git 基线与共享约束，按依赖和活动责任推进可派集合。

主控用 [主控执行](../lingflow-controller/SKILL.md) 派发，开发成员执行 [原票实施](../lingflow-implement/SKILL.md)。以实际报告、候选与适用审查收口。新结果产生时再判断下游是否解锁。保留用户原有改动；分支、合并、提交、推送按项目授权处理。
