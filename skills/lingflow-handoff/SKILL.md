# 交接与续接

- 上下文丢失时用 `context` 恢复职责，主控遵守其中的回合规则。收到续接卡后读 `inbox`，按卡片涉及的原票 `inspect`，核对实际阶段和负责人。接管时缺少任务范围才查 `list`，操作结果不明时沿原 ID 查 `operation`。
- 在项目认可的位置记录当前目标、确认范围、任务 ID、候选、已完成的检查、待处理问题和下一动作。引用现有文件，隐去凭据与无关个人数据。
- 交接给接续会话时保持原票和原操作 ID。普通进度用 `progress`，需要答复的阻塞用 `question`。没有可执行事项时立即结束回合，等待系统回投。禁止为等结果自行或委托他人轮询。
