# 选择入口

- 需求还在取舍阶段，选择 [需求追问](../lingflow-grilling/SKILL.md) 或 [讨论并落文档](../lingflow-grill-with-docs/SKILL.md)。
- 目标已经明确，选择 [规格](../lingflow-to-spec/SKILL.md)、[拆票](../lingflow-to-tickets/SKILL.md) 或 [主控执行](../lingflow-controller/SKILL.md)。
- 开发或排障，选择 [实施](../lingflow-implement/SKILL.md)、[测试先行](../lingflow-tdd/SKILL.md) 或 [诊断](../lingflow-diagnosing-bugs/SKILL.md)。
- 已派独立审查走 [审查](../lingflow-code-review/SKILL.md)，更换会话走 [交接](../lingflow-handoff/SKILL.md)。

按当前问题选择一个起点。用户只问该选什么时说明选择和下一步。
